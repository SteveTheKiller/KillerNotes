Install KillerMCP

KillerMCP includes all 81 KillerTools utilities plus tools from supported Killer apps in one local connection. The installer detects KillerNotes and registers that shared connection with supported agent clients.

Windows installer v0.1.0 coming soon
  1. Download and run KillerMCP Setup.
  2. Let setup connect your agent. It registers KillerMCP with Codex, Claude Code, Claude Desktop, Cursor, GitHub Copilot, Gemini CLI, and Windsurf when found. No source checkout, Node installation, or manual command list is required.
  3. Open a new agent chat and ask. Available tools are discovered automatically.

Optional hosted KillerTools connection

The hosted endpoint provides 64 browser based KillerTools utilities without an installation. It does not provide access to KillerNotes or any files on your computer.

What it can do

KillerMCP currently provides one bounded, read-only KillerNotes search tool.

Search titlesFind notes whose title matches the requested text.
Search tags and textMatch note tags and content, then return useful snippets.
Limit the resultReturn from 1 to 20 matches. The default is 10.
Make no changesThe tool cannot create, edit, move, or delete notes.

Data safety and permissions

The KillerNotes search runs locally through the installed app. It reads the active local notes database and returns only the bounded matches to the MCP client and its agent. The hosted Cloudflare Worker never receives this notes search.

Your MCP client and model provider can still receive the search request and returned titles, tags, and snippets. Apply that provider's data handling rules, and do not request client or confidential material unless its use is allowed.

How it works

KillerMCP is an open-source local runtime. It starts one MCP connection, detects installed Killer apps, and exposes only the adapters supported by those installed versions. For this page, it calls the KillerNotes command line search and validates the bounded JSON response.

The optional public endpoint is a separate open-source MCP server running as a Cloudflare Worker. Tool requests sent to that URL are processed on Cloudflare, and lookup tools may contact their named public data sources. It cannot reach the local KillerNotes database.

Current limits

Queries are limited to 200 characters and responses to 20 matches. Encrypted KillerNotes databases cannot currently be unlocked through MCP. The public installer is still being prepared and has not been released.
