Install KillerMCP

KillerMCP includes all 81 KillerTools utilities plus tools from supported Killer apps in one local connection. The installer detects KillerNotes and registers that shared connection with supported agent clients.

  1. Download and run KillerMCP Setup.
  2. Let setup connect your agent. It registers KillerMCP with Codex, Claude Code, Claude Desktop, Cursor, GitHub Copilot, Gemini CLI, and Windsurf when found. No source checkout, Node installation, or manual command list is required.
  3. Open a new agent chat and ask. Available tools are discovered automatically.

Try asking

killer is the shortest form. Your agent can infer KillerNotes from a clear notes request. Use killernotes when you want to make the app explicit.

What it can do

KillerMCP currently provides one bounded, read-only KillerNotes search tool.

Search titlesFind notes whose title matches the requested text.
Search tags and textMatch note tags and content, then return useful snippets.
Limit the resultReturn from 1 to 20 matches. The default is 10.
Make no changesThe tool cannot create, edit, move, or delete notes.

Data safety and permissions

The KillerNotes search runs locally through the installed app. It reads the active local notes database and returns only the bounded matches to the MCP client and its agent.

How it works

KillerMCP is a small program that lets your AI assistant use supported Killer apps installed on your computer. You install and connect it once, and it automatically finds the apps and tools available on your computer. When you ask your assistant to search your notes, KillerMCP checks the request, asks KillerNotes to search the local notes database, limits the number of matches, and gives the results back to your assistant. The search is performed by the installed KillerNotes app, not by this webpage.

Current limits

  • Queries are limited to 200 characters.
  • Responses are limited to 20 matches.
  • Encrypted KillerNotes databases cannot currently be unlocked through MCP.
  • The public installer is still being prepared and has not been released.
